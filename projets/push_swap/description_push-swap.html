Push-swap

Push-swap est un projet développé en Go dont l'objectif est de trier une liste d'entiers en utilisant deux piles et un ensemble limité de 11 instructions. Le défi consiste à trouver une suite d'opérations permettant de trier les valeurs dans l'ordre croissant avec le moins de coups possible. Le projet est composé de deux programmes indépendants : push-swap, qui calcule les instructions de tri, et checker, qui les exécute et vérifie le résultat.

Présentation du projet

Le concept et les objectifs de Push-swap.

Le concept

Push-swap consiste à trier une liste d'entiers placée dans une pile appelée A, en utilisant une seconde pile appelée B. Les déplacements et modifications sont réalisés uniquement grâce aux instructions autorisées par le sujet.

Les objectifs

L'objectif principal est de développer un algorithme capable de trier les valeurs dans l'ordre croissant en minimisant le nombre d'instructions utilisées. La qualité du programme dépend donc autant du résultat que de son optimisation.

Deux programmes

Le projet est composé de deux exécutables. Push-swap génère une suite d'instructions pour trier les valeurs, tandis que checker lit et exécute ces instructions afin de vérifier si la pile A est triée et si la pile B est vide.

Fonctionnement du projet

Les différentes étapes de traitement et de vérification.

1. Initialisation des piles

Les entiers reçus en arguments sont récupérés et placés dans la pile A, dans le même ordre que celui fourni. La pile B est initialement vide.

Arguments Pile A Pile B

2. Calcul des instructions

Le programme push-swap analyse les valeurs présentes dans les piles et détermine les opérations à effectuer pour obtenir un tri. Il cherche à réduire au maximum le nombre de déplacements nécessaires.

Algorithmes Optimisation

3. Vérification du résultat

Le programme checker récupère les instructions depuis l'entrée standard et les exécute. Il affiche OK si la pile A est triée et que la pile B est vide, sinon il affiche KO.

Checker Validation

Exemple d'utilisation

Le programme reçoit une liste d'entiers et génère les instructions nécessaires à son tri. Ces instructions peuvent ensuite être directement transmises au programme checker. 

ARG="4 67 3 87 23"

./push-swap "$ARG" | wc -l

./push-swap "$ARG" | ./checker "$ARG"

La première commande permet de compter le nombre d'instructions générées. La seconde vérifie automatiquement si le résultat du tri est correct.

Les 11 instructions

Les opérations autorisées pour manipuler les deux piles.

Déplacement entre les piles

Ces instructions permettent de déplacer l'élément situé au sommet d'une pile vers le sommet de l'autre.

pa : B vers A pb : A vers B

Échange des éléments

Ces opérations échangent les deux premiers éléments d'une pile. L'instruction ss effectue les deux échanges simultanément.

sa sb ss

Rotation vers le haut

La rotation décale tous les éléments d'une position vers le haut : le premier élément devient le dernier. Les deux piles peuvent également être tournées simultanément.

ra rb rr

Rotation vers le bas

La rotation inverse décale les éléments d'une position vers le bas : le dernier élément devient le premier. L'instruction rrr agit sur les deux piles.

rra rrb rrr

Algorithmes de tri

Les différentes stratégies utilisées pour réduire le nombre d'instructions.

Tri des petites piles

Pour les petites listes, des algorithmes spécifiques permettent de trouver rapidement une solution avec très peu d'instructions. Le programme adapte sa méthode en fonction du nombre d'éléments à trier.

Tri des grandes piles

Lorsque le nombre de valeurs augmente, il devient nécessaire d'utiliser une stratégie plus adaptée. L'objectif est d'organiser les déplacements entre les deux piles afin de limiter les rotations et les échanges.

Optimisation des déplacements

Le programme peut combiner plusieurs instructions pour effectuer des opérations simultanément. Les rotations communes permettent notamment de réduire le nombre total de coups nécessaires.

Les difficultés du projet

Les principaux défis rencontrés pendant le développement.

Manipulation des piles

Les opérations de rotation et de déplacement nécessitent une bonne gestion des indices et des slices en Go. Une erreur dans les positions peut rapidement provoquer un résultat incorrect.

Optimisation du tri

Trouver une solution qui trie correctement les valeurs ne suffit pas. Il faut également chercher à réduire le nombre d'instructions, ce qui demande de comparer différentes stratégies.

Gestion des cas particuliers

Le programme doit gérer les listes déjà triées, les petites quantités de valeurs, les nombres négatifs, les doublons et les arguments invalides. Chaque situation doit être correctement traitée.
