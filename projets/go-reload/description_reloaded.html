Go-reloaded

Go-reloaded est un outil en ligne de commande développé en Go. Son objectif est de lire un fichier texte, d'appliquer automatiquement différentes règles de transformation, puis d'écrire le résultat dans un nouveau fichier. Ce projet permet de mettre en pratique la manipulation de chaînes de caractères, les conversions numériques et la gestion de fichiers.

Présentation du projet

Le concept et les objectifs de Go-reloaded.

Le concept

Go-reloaded est un programme qui modifie automatiquement un texte à partir de règles prédéfinies. Il permet notamment de corriger certaines erreurs de ponctuation, de transformer la casse des mots et de convertir des nombres.

Les objectifs

L'objectif est de créer un outil capable de lire un fichier d'entrée, de traiter son contenu selon différentes règles, puis de générer un fichier de sortie contenant le texte transformé.

Le fonctionnement

Le programme reçoit deux arguments : le nom du fichier à lire et celui du fichier dans lequel enregistrer le résultat. Les modifications sont appliquées au texte avant son écriture.

Fonctionnement du programme

Les différentes étapes du traitement du texte.

1. Lecture du fichier

Le programme récupère le contenu du fichier d'entrée grâce aux fonctionnalités de gestion des fichiers de la bibliothèque standard de Go.

Fichier source Lecture

2. Transformation du texte

Le contenu est analysé et les différentes règles sont appliquées : conversion des nombres, modification des mots, correction de la ponctuation et ajustements grammaticaux.

Chaînes de caractères Règles de traitement

3. Écriture du résultat

Une fois le traitement terminé, le texte corrigé est enregistré dans le fichier de sortie demandé. Le fichier d'entrée reste distinct du résultat.

Fichier de sortie Écriture

Exemple d'utilisation

Le programme peut transformer des nombres hexadécimaux ou binaires en nombres décimaux, puis enregistrer le texte modifié. 

go run . sample.txt result.txt

Par exemple, la transformation de 42 (hex) donne 66, tandis que 10 (bin) donne 2.

Les règles de transformation

Les principales règles que le programme doit appliquer.

Conversions numériques

Les balises (hex) et (bin) permettent de convertir le nombre qui les précède en base décimale.

Hexadécimal Binaire Décimal

Modification de la casse

Les balises (up), (low) et (cap) permettent respectivement de mettre des mots en majuscules, en minuscules ou avec une majuscule initiale. Un nombre peut préciser combien de mots précédents doivent être modifiés.

Majuscules Minuscules Capitalisation

Correction de la ponctuation

Le programme doit replacer correctement les signes de ponctuation, supprimer les espaces incorrects et conserver les groupes de signes comme les points de suspension ou les doubles signes d'exclamation.

Ponctuation Espacement Apostrophes

Correction grammaticale

Le programme doit transformer l'article anglais « a » en « an » lorsque le mot suivant commence par une voyelle ou par la lettre h, en tenant compte des exemples prévus dans le sujet.

Anglais Règles grammaticales

Technologies utilisées

Les langages, packages et outils mobilisés dans le projet.

Go

Langage utilisé pour développer l'ensemble du programme, organiser le code et implémenter les règles de transformation du texte.

Go Fonctions Chaînes de caractères

Gestion des fichiers

Le package os permet notamment de récupérer les arguments de la commande, de lire un fichier et d'écrire le résultat dans un autre fichier.

os.Args os.ReadFile os.WriteFile

Manipulation du texte

Le package strings fournit des outils pour découper, assembler et transformer les chaînes de caractères pendant le traitement.

strings.Fields strings.ToUpper strings.ToLower

Conversions numériques

Le package strconv permet de convertir des nombres représentés sous forme de texte et de traiter les bases numériques utilisées dans les balises du projet.

strconv.ParseInt Base 2 Base 16

Tests et qualité du code

Les tests unitaires permettent de vérifier chaque règle, de détecter les erreurs et de s'assurer que les modifications ne cassent pas les fonctionnalités déjà développées.

testing go test gofmt

Les difficultés du projet

Les points qui demandent une attention particulière.

Ordre des transformations

Certaines règles peuvent se suivre ou interagir. Il faut donc organiser leur application pour éviter qu'une transformation perturbe les suivantes.

Gestion de la ponctuation

Les signes isolés, les groupes de ponctuation et les apostrophes entourant plusieurs mots nécessitent un traitement précis des espaces.

Tests et cas particuliers

Les exemples du sujet ne couvrent pas toutes les situations. Il est important de tester les limites, les erreurs et les combinaisons de plusieurs règles.
